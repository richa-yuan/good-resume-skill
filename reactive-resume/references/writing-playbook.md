# 简历与求职信写作手册

## 第一原则：写成就，不写职责

"负责活动执行"是职责描述——它告诉 HR 你的岗位说明书，没有告诉 HR 你多强。
"从 0 到 1 操盘双十一大促，GMV 同比 +58%，活动 ROI 从 1.8 提升到 3.2"是成就描述。

**改写公式**：`动词 + 对象 + 方法/手段 + 量化结果`。

| 职责版（避免） | 成就版（推荐） |
|---|---|
| 负责公司官网的日常维护 | 重构官网信息架构，自然流量 +35%，跳出率下降 12 个百分点 |
| 做用户增长相关的工作 | 搭建裂变拉新体系，3 个月获客成本从 ¥28 降至 ¥11，新增用户 40 万 |
| 参与客户销售与跟进 | 独立负责华东区 12 家大客户，年度续约率 95%，超额完成指标 23% |
| 带新人熟悉业务 | 带 3 名新人，2 个月内独立承接需求，组内评审一次通过率 98% |

> 上表覆盖运营 / 研发 / 销售 / 管理四个方向，只是示例。本技能适用于**任意行业**——把你的真实数字填进公式即可，没有数字时按下文"追问术"去挖。

## STAR：一条 bullet 的骨架

- **S（情境）**：事情的背景和难点。简历里通常压缩成半句（"大促前""从 0 到 1"）。
- **T（任务）**：你承担什么。默认省略主语"我"——简历里主语是你，不用写。
- **A（行动）**：你具体做了什么、用什么方法。这是区分"参与者"和"主导者"的地方，用词要准（`主导 / 设计 / 推动 / 落地`）。
- **R（结果）**：能量化必须量化。数字类型参考下表。

## 数字从哪里来（追问术）

用户说"效果挺好的"时，按这个清单挖：

1. **规模**：用户量 / DAU / 订单量 / 数据量 / 客户数 / 覆盖门店数 / 管理人数
2. **幅度**：提升 / 下降百分之多少？从多少到多少？
3. **速度**：快了多少秒？交付周期从几周缩到几天？
4. **范围**：影响多少页面 / 多少业务线 / 多少人？
5. **对比**：行业平均水平如何？优化前后如何？
6. **成本**：省了多少人力 / 服务器 / 预算？

挖不到真实数字时的处理：用范围（"覆盖 80% 业务场景"）或定性表述（"成为团队标准方案"），**绝不允许编数字**。编的数字面试官一问就穿帮，且违背本技能"不编造"的底线。

## 中文动词表（按场景选，避免重复）

- **技术研发**：设计 / 主导 / 重构 / 落地 / 攻克 / 优化 / 沉淀 / 搭建 / 迁移 / 治理
- **数据算法**：构建 / 训练 / 挖掘 / 建模 / 验证 / 量化 / 归因
- **产品运营**：策划 / 统筹 / 推进 / 复盘 / 裂变 / 拉新 / 促活 / 留存
- **设计创意**：重构 / 规范 / 提效 / 统一 / 改版 / 验证
- **销售市场**：开拓 / 签约 / 达成 / 超额 / 复购 / 续约
- **管理协作**：带教 / 统筹 / 对齐 / 推动 / 拆解 / 把关 / 复盘

一段经历内同一动词最多出现两次；换同义词时保持力度（别把"主导"降级成"参与"）。

## 个人摘要公式

```
X 年 [领域] 经验，[最强身份标签]；擅长 [技能 1]、[技能 2]、[技能 3]；
[最亮眼的一个量化成果]；寻求 [目标岗位] 机会。
```

示例（研发 / 运营 / 销售 三选一，可替换为你的行业）：
> 5 年互联网产品经验，2 年团队负责人；擅长 0→1 产品搭建、增长策略与跨团队协同；主导过日活百万级 C 端产品改版，月留存提升 18 个百分点；寻求高级产品经理岗位。

> 4 年用户增长经验；擅长裂变拉新、活动操盘与数据复盘；操盘过双十一大促 GMV 同比 +58%，获客成本下降 60%；寻求用户增长负责人岗位。

> 6 年 B 端销售经验，3 年大客户团队管理；擅长客户拓展、谈判与续约经营；连续两年超额完成指标 20%+，团队年度续约率 95%；寻求区域销售总监岗位。

要点：数字只放最亮眼的一个；技能写 JD 里出现过的；"寻求……岗位"让 HR 一秒对齐。

## 求职信三段式

1. **为什么是你们**：引用具体事实——某个产品、某次技术分享、某条新闻。忌"久闻大名""贵公司行业领先"这类空话。
2. **为什么是我**：挑 2–3 个与 JD 最强的匹配证据，每个一句话带数字，与简历互为印证而非重复。
3. **收尾**：表达面试意愿 + 一个具体的下一步（"期待有机会当面详谈"即可，别催促）。

## 常见错误清单

- 段落第一条写"职责范围"而不是最大成就 → 排序按含金量，不按时间倒序（同公司内）
- 满篇"熟悉""了解""参与" → 力度词升级，但必须与事实相符
- 技能关键词罗列 20 个 → 与目标 JD 相关的留下，其他删
- 一份简历投所有公司 → 至少按 JD 换摘要、技能关键词和前两条 bullet
- 时间线有断档 → 如实处理（写"自由职业/学习进修"或准备说辞），别留空
- 中英混排不统一 → 专有名词保留英文，其余统一中文

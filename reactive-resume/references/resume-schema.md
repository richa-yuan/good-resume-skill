# 简历数据结构（resume.json）

> 字段设计参考 reactive-resume 的 `resumeDataSchema`，已中文化。**这是契约**：写文件和改文件都按这个结构来，`validate_resume.py` 按它校验。

## 顶层结构

```json
{
  "版本": "1.0",
  "基本信息": { "姓名": "", "头衔": "", "手机": "", "邮箱": "", "城市": "", "个人网站": {"url": "", "label": ""}, "自定义字段": [] },
  "头像": { "隐藏": true, "url": "" },
  "个人摘要": { "标题": "个人简介", "内容": "", "隐藏": false },
  "区块": [ { "类型": "经历", "标题": "工作经历", "隐藏": false, "条目": [] } ],
  "自定义区块": [],
  "排版": { "纸张": "a4", "布局": "单栏", "主色": "#2f6feb", "正文字号": 10.5 }
}
```

| 字段 | 说明 |
|---|---|
| `版本` | schema 版本，当前固定 `"1.0"` |
| `基本信息` | 姓名、头衔、联系方式。姓名/手机/邮箱是 ATS 必填 |
| `头像` | 默认 `隐藏: true`——多数 ATS 场景不建议放照片；国企/部分行业可开 |
| `个人摘要` | 3–5 句话：X 年 Y 领域经验 + 最强技能 + 最亮眼成果 + 求职方向 |
| `区块` | 有序数组，顺序即简历中的展示顺序 |
| `自定义区块` | 放不进的 niche 内容（专利、课程、演讲……），条目同 `区块` 的条目结构 |
| `排版` | 模板参数，仅影响渲染，见 `templates.md` |

## 区块类型与条目字段

每个区块：`{ "类型": ..., "标题": ..., "隐藏": false, "条目": [...] }`。
所有条目通用字段：`id`（字符串，唯一即可）、`隐藏`（布尔，临时下架某条而不删除）。

### 经历（experience）— 简历的主体

```json
{
  "id": "exp-1",
  "公司": "某电商公司",
  "职位": "运营专员",
  "地点": "杭州",
  "开始": "2021-03",
  "结束": "2024-06",
  "描述": "<ul><li>...</li></ul>",
  "子角色": []
}
```

- `开始` / `结束`：`YYYY-MM`；在职中 `结束` 写 `"至今"`。
- `描述`：HTML `<ul><li>` 列表（渲染器认这个）；每条 bullet 一条成就。
- `子角色`：同公司内部晋升/转岗时使用，字段同条目去掉 `公司`，按时间倒序排列。

### 教育（education）

```json
{ "id": "edu-1", "学校": "某大学", "学位": "本科", "专业": "计算机科学与技术", "成绩": "GPA 3.6/4.0", "地点": "杭州", "开始": "2016-09", "结束": "2020-06", "描述": "" }
```

工作 3 年以上时教育经历放最后、只留一行；应届生可展开主修课程。

### 项目（projects）

```json
{ "id": "proj-1", "名称": "小程序商城重构", "开始": "2022-04", "结束": "2022-09", "网站": {"url": "https://...", "label": "项目链接"}, "描述": "<ul><li>...</li></ul>" }
```

### 技能（skills）

```json
{ "id": "skill-1", "名称": "数据分析", "熟练度": "熟练", "等级": 4, "关键词": ["Python", "SQL", "AB 实验", "数据看板"] }
```

- `等级` 0–5，`0` 表示不显示等级（推荐做法：等级主观，关键词更诚实）。
- `关键词` 是 ATS 关键词的主要载体，从 JD 里映射。

### 语言（languages）/ 兴趣（interests）

```json
{ "id": "lang-1", "语言": "英语", "流利度": "CET-6 / 可读写技术文档", "等级": 3 }
{ "id": "int-1", "名称": "行业社群", "关键词": ["增长黑客社区", "运营沙龙分享"] }
```

### 奖项 / 证书 / 出版物 / 志愿 / 推荐人 / 社交

```json
{ "id": "award-1", "标题": "年度优秀员工", "颁奖方": "某电商公司", "日期": "2023-12", "网站": {"url": "", "label": ""}, "描述": "" }
{ "id": "cert-1", "名称": "PMP（项目管理专业人士）", "颁发机构": "PMI", "日期": "2023-05", "网站": {"url": "", "label": ""}, "描述": "" }
{ "id": "pub-1", "标题": "论文/文章标题", "出版商": "出版社/期刊/掘金", "日期": "2023-08", "网站": {"url": "", "label": ""}, "描述": "" }
{ "id": "vol-1", "组织": "某公益基金会", "地点": "线上", "开始": "2022-01", "结束": "2022-12", "描述": "" }
{ "id": "ref-1", "姓名": "张某", "职位": "前主管", "电话": "", "描述": "" }
{ "id": "prof-1", "网络": "GitHub", "用户名": "zhangsan", "网站": {"url": "https://github.com/zhangsan", "label": "GitHub"} }
```

推荐人默认写"可应要求提供"并 `隐藏: true`，需要时再开。

### 摘要（summary）与求职信（cover-letter）

```json
{ "类型": "摘要", "标题": "个人简介", "条目": [ { "id": "sum-1", "内容": "5 年互联网运营经验……" } ] }
{ "类型": "求职信", "标题": "求职信", "条目": [ { "id": "cl-1", "收件人": "招聘负责人", "内容": "……" } ] }
```

## 变体提示

- **应届生**：教育前置，加"主修课程"区块；经历用实习+项目补足；摘要突出学习能力和相关课程/竞赛。
- **技术岗**：技能和项目权重最高，附 GitHub/作品链接；经历 bullet 全部量化。
- **国企/传统行业**：可开启头像；格式从简从稳，避免花哨模板；补充"政治面貌"等自定义字段。
- **学术/研究**：出版物区块前置，教育经历写清导师和课题。

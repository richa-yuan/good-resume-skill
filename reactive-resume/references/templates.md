# 模板与排版指南

## 选型矩阵

| 你的情况 | 推荐布局 | 说明 |
|---|---|---|
| 投互联网/外企（过 ATS） | 单栏 · 简洁 | 机器读得顺永远是第一优先 |
| 国企/事业单位/传统行业 | 单栏 · 稳重 | 可开头像，少用色彩 |
| 设计/创意类岗位 | 双栏 · 有设计感 | 人眼优先，附 PDF 作品集 |
| 学术/研究岗位 | 单栏 · 紧凑 | 出版物前置，信息密度优先 |
| 应届生 | 单栏 · 教育优先 | 内容不够时靠课程/项目/证书补 |

**默认建议：单栏。** 除非明确不过 ATS，不要为视觉牺牲可解析性。

## 排版参数（A4 基准）

| 参数 | 建议值 | 说明 |
|---|---|---|
| 纸张 | A4（投外企可用 Letter） | 按目标地区选 |
| 页边距 | 上下 1.6–2.0cm，左右 1.8–2.2cm | 别低于 1.5cm，打印会裁字 |
| 姓名 | 18–22pt 加粗 | 全文最大字 |
| 区块标题 | 11–12pt 加粗，可带主色下划线 | 让 HR 3 秒定位到相关区块 |
| 正文 | 10–10.5pt | 不低于 9pt |
| 行距 | 1.3–1.5 | 密而不挤 |
| 条目间距 | 段后 4–6pt | 用间距分层，别用分隔线堆砌 |
| 主色 | 一个就够（如 #2f6feb） | 只用于标题/分隔线，不用于正文 |

## 结构顺序（单栏模板）

```
姓名（最大）+ 头衔
联系方式一行：手机 | 邮箱 | 城市 | 链接

个人简介（3–5 句）
工作经历（倒序，每条 3–5 个 bullet）
代表项目（可选，与经历互补而非重复）
专业技能（关键词分组）
教育经历（3 年以上经验放这里）
其他：证书 / 语言 / 兴趣（一行带过）
```

区块顺序可在 `resume.json` 的 `区块` 数组里调整——**顺序即数据的一部分**，换岗位时调整数组顺序即可，不用改模板。

## 导出路径

本技能负责内容与结构，成品导出交给对应工具：

1. **Markdown**：`validate_resume.py render` 直接产出，适合投递前快速过稿和存档。
2. **HTML → 打印为 PDF**：`render --format html` 产出单栏 HTML，浏览器打开后 `Cmd/Ctrl + P`，选"背景图形：关"、"缩放：默认"，得到文本型 PDF（ATS 可解析）。
3. **Word / 精致 PDF**：内容定稿后，交给环境里的 `docx` / `pdf` 技能做最终排版。

## 版本与命名规范

- 原版：`resume.json`
- 定制版：`resume-<公司名>.json`（原版永不覆盖）
- 成品：`outputs/姓名-职位-公司-日期.md|.pdf`
